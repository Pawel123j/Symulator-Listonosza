# Architecture Decision Records (ADR)

**English** · [Polski](README.md)

Architecture decisions are recorded in the [MADR](https://adr.github.io/madr/) format.
Each significant choice gets its own `NNNN-title.md` file. Numbers only go up and accepted ADRs
are not edited — when a decision changes, a new ADR is added and the old one is marked
*superseded by NNNN*.
